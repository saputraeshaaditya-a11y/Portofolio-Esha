Skematik Sirkuit Wokwi / Fritzing

Arduino Uno R3

Rangkaian otomatisasi pendeteksi suhu laboratorium menggunakan Sensor DHT11, Layar LCD 16x2 I2C, serta Motor Servo SG90.

Simulasi Wokwi Online Status: Verified Sketch

Program C/C++ Sketch

sketch.ino

#include <DHT.h>

#include <LiquidCrystal_I2C.h>

#include <Servo.h>

// Inisialisasi Hardware

#define DHTPIN 2

#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

Servo servoKipas;

void setup() {

dht.begin();

servoKipas.attach(9);

}

void loop() {

float t = dht.readTemperature();

if (t > 30.0) {

servoKipas.write(90);

}

}

Bahasa: C++
